# Handoff：財務管家 版面改版（色塊儀表板 · 淺色 E ＋ 深色 G）

## Overview
把現有 `my-finance-app`（React 19 + Vite + Tailwind v4 的個人財務 PWA）的視覺與版面換成「色塊儀表板」風格 — 深色 icon 側欄、米白畫布、大面積飽和色塊卡、橘色 CTA、粗描邊與黑色膠囊標籤 — 並提供成對的淺色／深色兩套色票。功能、資料模型、ledger 規則完全不變，這是純版面與 token 的改版。

改動要點：
1. 外殼改為 **深色底盤（#1c1c1c，padding 12px）包住一張米白圓角畫布（#faf7f2, radius 18px）**；側欄是底盤上的 64px icon rail，不是分隔的面板。
2. **每家銀行一個顏色**（黃／紫／藍／綠），在帳戶列、交易 icon、卡片背景一致沿用 — 使用者靠顏色認銀行，不靠讀字。
3. KPI 從白底卡改為 **三張飽和色塊卡**（總資產黃、投資紫、待繳藍），每張帶一條佔比進度條（現金佔總資產／投資佔比／繳款完成度）。
4. 所有元件用 **1.5–2.5px 實心描邊 + 高圓角（14–24px）**，不用陰影分層。
5. 主要動作一律 **橘色實心膠囊 #d4400f**；次要動作是描邊膠囊。
6. 總覽右欄是一張 **深色 spotlight 面板**，只講「最近要繳的一筆」。
7. 手機底部導覽是 **深色浮動膠囊**，active 為黃色 pill 帶文字。
8. 色票整併為一組語意 token，`.dark` 只重新定義同名變數（沿用專案現有做法）。

## About the Design Files
此 bundle 內的 `.dc.html` 是**設計參考稿（design reference），以 HTML 手寫的高擬真原型**，不是可直接搬進 repo 的生產程式碼。它們用 inline style 表達最終視覺，沒有元件化、沒有狀態、沒有 Tailwind class。

實作方式：**在既有 React + Vite + Tailwind v4 環境中重建這些畫面**，沿用專案現有架構與硬性約束（見「必須遵守的既有約束」），把顏色寫進 `src/index.css` 的 `@theme` / `:root` / `.dark` token，元件端只用語意 utility（`bg-surface`、`text-ink-2`…），不要把 hex 直接寫在元件裡，也不要照抄 inline style。

## Fidelity
**High-fidelity。** 顏色、字級、字重、間距、圓角、描邊寬度都是最終值，請照數值實作。可自由發揮的只有 hover／focus／transition 細節（沿用專案現有 `transition` 慣例）。

畫面中的金額、銀行名稱、股票名稱皆為示意資料。

## 必須遵守的既有約束（來自 repo 的 CLAUDE.md，改版不得破壞）
- **不同幣別永不相加**：所有合計走 `sumByCurrency()`，分行呈現。中國信託那張卡是「TWD 一列、USD 一列」，不是一個總數。
- **金額只透過 `formatMoney`／`useMoneyFormat()` 輸出**，隱藏金額功能靠這個單一出口。
- **金錢變動只走 `lib/ledger.js`**；本改版不新增任何 mutation。
- **手動改餘額要留 `adjustment` 紀錄**。
- **safe-area inset 是相加的**：`safe-area-pt` 留在 `<main>`，內距放內層容器。手機浮動膠囊導覽需 `bottom: calc(18px + env(safe-area-inset-bottom))`。
- **Theming 是 token，不是逐 utility 覆寫**。

## Interactions & Behavior
沿用現有行為，不新增流程：
- 側欄／底部導覽切換 `tab` state；`aria-current="page"` 標記 active。
- 幣別切換沿用 `readPref('balance-currency')`，作用範圍為 KPI 與各頁合計。
- 隱藏金額：`MoneyFormatContext` 既有機制；遮罩時每種幣別字串相同，只顯示一組。
- 帳戶卡的編輯／刪除收在右上「⋯」動作選單（沿用既有 `actionsFor` 模式），桌機 hover／focus-within 顯示，手機常駐。
- 繳款鈕：3 天內到期＝橘色實心「立即繳款」，其他＝描邊「手動繳款」，已繳不再有鈕。
- 進度條數值：現金佔比＝現金 ÷（現金＋投資成本）；繳款完成度＝已繳張數 ÷ 總張數。純函式，建議放 `lib/` 並附測試。
- Toast、ConfirmDialog、錯誤訊息維持現況（錯誤 6 秒、成功 3 秒）。
- Transition 沿用現有 150ms 色彩／不透明度過渡；`prefers-reduced-motion` 已在 `index.css` 處理。
- **描邊風格的 hover**：建議只加 2px 位移陰影或背景加深，不要改描邊寬度（避免版面跳動）。
- 響應式：`md` 以下側欄收成底部浮動膠囊、KPI 三色塊改為 1 欄 + 2 欄、銀行卡與表格改為單欄堆疊（見手機稿）。

| `layout-e-blocks.dc.html` | **淺色版**（主稿）：總覽桌機／總覽手機／銀行帳戶／信用卡／投資／設定／記帳 Modal／鎖定畫面 |

檔案是單檔 HTML，直接用瀏覽器開即可；每個畫面外層有 `data-screen-label` 方便定位。頁面採橫向排列，可自由縮放檢視。

## 建議實作順序
1. `src/index.css`：改 `@theme` / `:root` / `.dark` token 值＋換字體（先做，其他頁自動跟著變）。
2. `App.jsx`：外殼改「深色底盤包米白畫布」、側欄改 64px icon rail、手機導覽改深色浮動膠囊、頂列抽成 `<TopBar>`。
3. `Dashboard.jsx`：KPI 改三色塊（含佔比條）＋ 左白面板（帳戶／紀錄）＋ 右深色 spotlight。
4. `AccountManager.jsx`／`CardManager.jsx`／`InvestmentManager.jsx`：改為色塊卡與描邊表格，保留既有動作與手機動作 sheet。
5. `ui.jsx` Modal 視覺、`SettingsPage.jsx`、`LockScreen.jsx`。
6. 跑 `npm test`（ledger／卡片週期／Modal focus 行為應全綠）、`npm run lint`。
